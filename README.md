# Carro Serto — versão TypeScript

Esta versão mantém o visual do site estático original e migra o JavaScript interativo para TypeScript (`src/main.ts`). O Vite serve o site durante o desenvolvimento e compila os arquivos para publicação.

## Requisitos
- Node.js 20 ou superior

## Rodar no computador
1. Instale o Node.js: https://nodejs.org/
2. Abra um terminal nesta pasta.
3. Execute `npm install`
4. Execute `npm run dev`
5. Abra o endereço local mostrado no terminal.

## Gerar versão de publicação
Execute `npm run build`. Os arquivos finais serão criados na pasta `dist/`. Publique o conteúdo dessa pasta em uma hospedagem estática compatível.

## Importante
- O conteúdo dos artigos é demonstrativo; confira fontes, dados e datas antes de publicar.
- O formulário de newsletter é apenas visual e não salva e-mails.
- O site ainda não tem painel administrativo/CMS. Para publicar manualmente sem editar código, será necessário adicionar um CMS ou migrar para WordPress/Blogger.
- Insira código do Adsterra somente após cadastrar e validar o site na plataforma e revisar as políticas de privacidade e anúncios.
